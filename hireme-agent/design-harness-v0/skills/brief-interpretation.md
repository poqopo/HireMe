# Brief interpretation skill

## Input

클라이언트 요청, 대상, 채널, 일정, 전달물, 첨부 자산.

## Method

1. 요청을 communication objective와 production task로 분리한다.
2. 명시된 사실, 합리적 추론, 확인이 필요한 가정을 구분한다.
3. 성공 기준과 실패 조건을 관찰 가능한 문장으로 바꾼다.
4. 결과 제작을 막는 정보만 질문하고 나머지는 가정으로 기록한다.

## Output

`objective`, `audience`, `channel`, `deliverables`, `mustInclude`,
`mustAvoid`, `assumptions`, `openQuestions`를 가진 normalized brief.
