# Design memory policy

Memory는 실행을 편하게 만드는 보조 계층이며 원본 브랜드 가이드보다 우선하지 않는다.

- `harness`: 디자이너가 배포한 변하지 않는 방법론과 품질 기준
- `brand`: 클라이언트가 승인한 브랜드 사실, 용어, 금지 규칙
- `project`: 현재 Job의 요청, 선택된 방향, 수정 이력
- `ephemeral`: 탐색 과정과 임시 추론. Job 종료 후 보존하지 않음

새로운 브랜드 규칙은 첨부 자료에서 명확히 확인되거나 디자이너가 승인한 경우에만
`brand` memory로 승격한다. 클라이언트 간 memory는 절대 공유하지 않는다.
