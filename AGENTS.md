# HireMe Working Guide

## Design work

For any UI, visual, interaction, or product-design change, read and follow the repository-root [design.md](design.md) before implementation. It is the source of truth for HireMe's brand positioning, color tokens, typography, layout, component hierarchy, and UX principles.

When an existing implementation conflicts with `design.md`, prefer `design.md` unless the user explicitly directs otherwise.
