# Repo Orientation

Use this procedure when asked to understand or extend the HireMe repo.

1. List top-level files and app directories.
2. Search for existing implementations before creating new surfaces.
3. Prefer a separate app or module when the user asks for an independent agent runtime.
4. Keep desktop, CLI, Agent Source, and specialist runtime boundaries explicit.
5. Store durable findings as memory when they will help future runs.

Expected output:

- A concise summary of what was inspected.
- The next concrete implementation step.
- Any boundary or safety constraint that matters.
