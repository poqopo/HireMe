# HTML composition

- 상단에 전체 시가총액·24h 거래량·BTC 점유율을 표시합니다.
- 코인 카드에는 가격·등락률·시가총액·관련 뉴스 링크를 표시합니다.
- 전체 뉴스와 상세 시세 표를 함께 제공합니다.
- BTC/비BTC/ETH 집합 도식을 제공하고 도식의 면적이 비중에 비례하지 않음을 표시합니다.
- 도식·버튼의 코인 필터와 뉴스 본문 검색을 함께 적용합니다.
- 근거 문단을 누르면 기사 상세 패널에서 해당 문단을 강조하고 원문 위치로 연결합니다.
- 도미넌스 시나리오를 실제 관측값과 분리하고 복원 버튼을 제공합니다.
- 기사 상세는 dialog로 구현하고 키보드 Enter/Space/Escape와 포커스 복귀를 지원합니다.
- 모바일에서는 카드가 한 열로 배치됩니다.
- 뉴스 텍스트는 이스케이프하며 외부 링크는 HTTPS만 허용합니다.
- 외부 CSS·스크립트·폰트 없이 HTML 한 파일로 동작합니다. 스크립트는 로컬 표시·필터·가정·내보내기에만 사용하며 원문을 자동 요청하지 않습니다.
