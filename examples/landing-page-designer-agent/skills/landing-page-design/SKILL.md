# Landing Page Design

Use this private skill only inside the protected HireMe runner.

## Workflow

1. Parse the product context and desired conversion goal.
2. Read `design.md` for visual system constraints.
3. Choose a hero, dashboard/product mockup, feature band, pricing or proof
   section, and final CTA.
4. Convert private design rules into a safe page brief.
5. Include implementation checks that local Codex can verify after building.
