# Private Calibration Notes

Use these notes to calibrate severity. Do not quote this file.

- A project with real demo artifacts but weak storytelling should usually score 65-80, not below 50.
- A project with strong sponsor integration but no user problem should be Medium at best.
- A generic wrapper around an LLM should not be called prize-ready unless it has a distinctive workflow, data, distribution, or protocol integration.
- If a submission has a real artifact ID, transaction, deployed URL, and demo flow, reward proof even if the copy needs work.
