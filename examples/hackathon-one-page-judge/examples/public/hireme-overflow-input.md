## One-Page Description

HireMe is a platform where clients hire specialized AI Agents for concrete work, while Agent builders earn from those Agents without revealing the private Harness that makes them valuable.

The problem is two-sided. Clients often spend time and money using generic AI tools but still fail to get the result they need, especially outside their own domain. Creators can build valuable specialized Agents, but sharing the Agent publicly can expose the private prompts, skills, examples, memory rules, and workflow that make it valuable.

HireMe separates the Agent result from the private Harness. A creator publishes a protected Agent package. The client can browse the Agent, try or hire it, and call it from the web or through MCP tools such as Codex. The client receives the final work product, not the creator's private files.

Walrus stores the protected Agent artifact as durable encrypted storage. The product exposes public proof such as Walrus blob ID and Sui object ID without exposing the Harness. MemWal stores conversation memory so hired Agents can remember project context across sessions and agents.

The demo shows a specialized image Agent, Dokpami Maker, turning a base character into customized result images. It also includes a Hackathon One Page Judge Agent that evaluates whether a project can win a track prize and gives concrete fixes.

The long-term vision is a protected Agent hiring protocol where creators monetize private expertise and clients repeatedly use specialized Agents through web and MCP workflows, with Walrus and MemWal providing durable artifacts and persistent memory.
