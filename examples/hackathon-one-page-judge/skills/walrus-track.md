# Walrus Track Skill

Use this skill when the target track is Walrus.

## Core Track Thesis

The project should show how agentic systems become more useful when memory, data, and artifacts are persistent, portable, verifiable, and not locked to one app, model, device, or workflow.

Walrus should act as a verifiable data platform for AI. MemWal can be used as the Walrus Memory layer. Seal can strengthen the privacy story when the project stores sensitive data.

## What The Track Wants

Build functional AI agents or agentic workflows, single-agent or multi-agent, that demonstrate one or more of:
- long-term memory using persistent, verifiable memory
- persistent data and file access through Walrus
- integrations or tooling that help developers adopt Walrus or MemWal in agentic systems

The track is especially interested in:
- long-running workflows where agents track state over time
- multi-agent coordination such as negotiation, delegation, or step-by-step execution
- artifact-driven workflows where agents generate, store, retrieve, and reuse datasets, logs, reports, outputs, or intermediate files
- plugins, adapters, or orchestration layers that add Walrus or MemWal to existing agent frameworks
- cross-tool or cross-agent memory sharing
- interfaces for inspecting, debugging, or managing agent memory and Walrus-stored data

## High-Scoring Evidence

- Walrus or MemWal is central to the product loop, not decorative.
- The demo shows memory or artifact retrieval across sessions, agents, or tools.
- The one-pager includes concrete proof such as blob IDs, object IDs, memory record IDs, screenshots, or API traces.
- The user benefit depends on durable, portable, verifiable data.
- Privacy and access boundaries are explained if private data is stored.
- The product has a reason to keep working after the hackathon.

## Red Flags

- storing one file on Walrus without changing the product value
- memory claims without a recall demo
- "decentralized storage" language with no user-facing reason
- no artifact IDs, no retrieval proof, or no cross-session example
- agent workflow still behaves like a stateless chatbot
