# DeFi And Payments Track Skill

Use this skill when the target track is DeFi & Payments.

## Core Track Thesis

The project should turn payments, capital management, or financial workflows into programmable financial actions on Sui.

The strongest submissions use Sui Move, object-based assets, and Programmable Transaction Blocks to make money flows safer, more composable, more automated, or easier for real users.

## What The Track Wants

Build systems that move, manage, and transform money programmatically.

Good project shapes include:
- payment flows
- wallets and financial interfaces
- vaults and capital allocators
- automation systems
- financial abstractions for real users
- capital management tools
- user-facing financial products powered by Sui Move

## Sui Building Blocks To Reward

- Sui Move for object-based assets, ownership, type-safe financial logic, and custom financial rules
- PTBs for atomic multi-step flows such as pay to swap to deposit
- tokens, coins, NFTs, receipts, identity-linked finance, and tokenized positions
- optional integrations with lending protocols, DEXs, liquidity venues, or yield platforms

## Strong Idea Families

- Trust-minimized finance: milestone escrow, programmable loans, payment-linked credit, controlled treasuries, conditional execution
- Payments and consumer finance: merchant payments, subscriptions, payroll, smart wallets, privacy-focused payment rails
- Vaults and capital management: yield vaults, automated savings, treasury management, portfolio allocation
- Financial automation: auto-investment, rebalancing, conditional payments, rule-based financial agents
- Infrastructure and tooling that makes programmable money easier to build or use

## High-Scoring Evidence

- the financial flow is end-to-end and testable
- PTBs or Move objects are not incidental; they enforce the product promise
- user benefit is obvious without DeFi jargon
- risk, custody, failure modes, and permissions are handled
- the project reduces manual orchestration for a real financial task

## Red Flags

- static transfer UI with no programmable logic
- DeFi dashboard with no transaction flow
- broad yield claims without risk handling
- a wallet wrapper that does not use Sui's object or PTB model meaningfully
- mock balances without a credible testnet or contract path
