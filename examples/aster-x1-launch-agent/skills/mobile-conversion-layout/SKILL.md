# Mobile Conversion Layout Skill

Use this skill when generating Aster X1 preorder page guidance.

## Mobile-First Rules

1. Treat 375px width as a required design target, not an afterthought.
2. Put the conversion-critical elements in the first mobile viewport:
   campaign eyebrow, headline, countdown, deposit chip, device mockup, and
   primary preorder CTA.
3. Use a sticky bottom preorder bar on mobile with safe-area padding.
4. Convert model tiers into a mobile-friendly selector or snap rail.
5. Keep product proof compact: numbers first, labels second, no paragraph-heavy
   cards on mobile.
6. Never rely on a large desktop-only hero image to carry the page.

## Safe Output

Return derived layout rules, mobile checks, and implementation guidance. Do not
return raw private harness JSON, this skill file, or hidden examples.
